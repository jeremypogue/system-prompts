# AGENTS.md

## GitHub Actions: not used

This repository does not use GitHub Actions and never will. Jeremy does not pay for Actions.

- Do not add, enable, re-enable or rely on GitHub Actions workflows.
- Do not report on Actions check runs, including failed or missing checks on pull requests. They are not this project's checks.
- Run tests and checks locally.
- The old workflow files are kept in `.github/workflows-disabled/` for reference only. Do not move them back into `.github/workflows/`.
